# Pyrsos brand

The mark is two beacon fires on two hills: the signal passed from hilltop to hilltop, as Pyrsos
passes messages from phone to phone.

The name **Pyrsos** and this logo are trademarks of the Pyrsos project; see
[`TRADEMARKS.md`](../TRADEMARKS.md).

## Files

| File | What it is |
| --- | --- |
| `logo.svg` | The app icon in colour: orange mark on black. |
| `logo-mono.svg` | The mark alone in one colour. Use it for themed icons, print, stamps and embroidery. Recolour it to any single colour. |
| `lockup.svg` | Mark and name side by side, for light backgrounds. |
| `lockup-night.svg` | The same, for black backgrounds. |
| `wordmark.svg` | The name in Latin letters: PYRSOS. |
| `wordmark-el.svg` | The name in Greek letters: ΠΥΡΣΟΣ. |

The Android launcher icon (`app/src/main/res/drawable/ic_launcher_foreground.xml`) is the same
mark, drawn on the 108dp adaptive-icon canvas inside the 66dp safe zone. The same drawable is used
for the monochrome (themed) icon.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Black | `#000000` | Icon background; one-colour print. |
| Night accent | `#FF8A50` | Mark on the icon; mark and name on black. |
| Day accent | `#B23C00` | Mark and name on white. |
| Ember | `#E8590C` | Brand colour for larger areas, such as the website. |
| White | `#FFFFFF` | Mark on ember or on photos. |

Always use one colour for the whole mark. Do not colour the fires and the hills differently.

## Lettering

The name is drawn, not typed. Its letters follow classical Athenian inscriptions in marble: every
letter the same width, one even line, a sigma with open arms, a round omicron. Always use the SVG
files; do not retype the name in another typeface.

Running text on the website and in documents is set in Commissioner (SIL Open Font License), which
has both Greek and Latin letters.

## Clear space

Keep empty space around the mark and the lockup on every side, at least a quarter of the mark's
height. Nothing else (text, edges, other logos) goes inside it.

## Minimum size

| Form | Smallest on screen | Smallest in print |
| --- | --- | --- |
| Mark alone | 20 px high | 6 mm high |
| Lockup | 24 px high | 7 mm high |
| Wordmark alone | 12 px high | 4 mm high |

## Do not

- stretch, slant or rotate the mark;
- add outlines, shadows, gradients or glow;
- change the hills, the fires or their spacing;
- put the mark on a busy photo without a plain background behind it.
